# Affect migration parity checklist

This checklist carries the complete 29-entry old-checkout inventory into the TanStack workspace. It records implementation locations and evidence boundaries. “Verified” is scoped to the named local, hosted development or synthetic check; it does not imply CI, publication, production deployment or external-provider delivery.

## Status legend

- Pending: implementation or required evidence has not been supplied.
- Implemented; verification pending: destination source exists, but the required focused check or runtime evidence is not yet recorded.
- Verified (scoped): the named focused check or synthetic fixture ran against the recorded local implementation. Hosted or integrated acceptance is called out separately.
- Partially verified: a bounded part of the behavior has evidence; the unverified remainder is stated in the status.
- Omitted: only for behavior the owner deliberately excludes, with a recorded reason.
- Historical external CLI evidence: the section below records the limitations of pinned Affect CLI 0.0.4; no alias or wrapper is implied.
